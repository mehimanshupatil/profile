## What it is

_Shillak_ (शिल्लक) is Marathi for "the balance left". Groups log shared income, spending and transfers, set monthly limits per category and track savings goals. One install can belong to several independent spaces.

## The hard part

Sync without a server. Devices exchange data directly over local Wi-Fi (WebRTC), QR code batches or a JSON file, so no internet is required.

## Privacy model

Data lives only in IndexedDB, encrypted at rest with AES-256-GCM using a key derived from the user's PIN (PBKDF2, 200k iterations). The key exists only in memory while the app is unlocked, and the app auto-locks after five minutes in the background. It has no accounts and no analytics.
