# himanshupatil.dev

Personal portfolio site of Himanshu Patil, a frontend-focused full-stack engineer. Built to impress recruiters and hiring managers; the site itself is a showcase of UI craft.

## Language

**Case Study**:
An in-depth page about one Featured Project: what it is, the hard problem, and how it was solved, with a live demo or video.
_Avoid_: Project page, portfolio item

**Featured Project**:
A project chosen to get a Case Study.
_Avoid_: Highlight, showcase

**Project**:
Anything the owner built that appears on the site; non-featured ones appear only as a card in a grid.
_Avoid_: Work, app, repo

**Post**:
A hand-written article by the owner, possibly embedding interactive demos.
_Avoid_: Blog, article, entry

**Lens**:
A tailored presentation of the site for one kind of reader (e.g. a design-system lead), re-composing the same facts with a different emphasis.
_Avoid_: Persona, mode, view, variant

## Generated content

**Question**:
A curated question a visitor can pick in "Ask me"; each Lens has its own set.
_Avoid_: Prompt, query

**Answer**:
The pre-generated, interactive UI response to a Question, replayed to the visitor as if streaming live.
_Avoid_: Response, reply, generation

**Fact Base**:
The owner-approved facts (career history, skills, project facts) that all generated content must be built from and may not go beyond.
_Avoid_: Profile, context, data

**Lake Bulletin**:
A daily snapshot of Mumbai's lake water stock, presented as a widget.
_Avoid_: Lake widget, water report

**Scoreboard**:
Lighthouse results for the owner's live sites, tracked over time.
_Avoid_: Perf dashboard, metrics
